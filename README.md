## 📌 Visão Executiva
Dados sem estratégia são apenas passivos de TI. Este repositório apresenta as fundações lógicas, *queries* avançadas e modelagens analíticas que utilizo para transformar dados brutos de sistemas de alta complexidade (SAP ECC, SAP B1, WMS e TMS) em *insights* acionáveis para o corpo diretivo.

## 🎯 Casos de Uso Documentados

### 1. Auditoria e *Gap Zero* em Logística (WMS)
- **Desafio:** Garantir a conciliação perfeita entre estoques físicos (Centros de Distribuição) e o sistema contábil, minimizando perdas.
- **Solução:** Scripts SQL para auditoria contínua e cruzamento de dados transacionais, garantindo aderência às normas de *Compliance* (SOX).

### 2. Modelagem Executiva de Rentabilidade
- **Desafio:** Visualização em tempo real de margens, CAPEX e OPEX consolidados durante processos de Fusões e Aquisições (M&A).
- **Solução:** Construção de dashboards estratégicos em Power BI com medidas DAX complexas para análise temporal e projeções financeiras.

## 📁 Estrutura de Arquivos
- `/sql_scripts`: Rotinas de ETL, *Stored Procedures* e otimização de consultas (Performance Tuning).
- `/powerbi_templates`: Arquivos `.pbit` estruturais para DRE e Balanced Scorecard (BSC).
- `/governance`: *Checklists* e matrizes de Segregação de Funções (SoD) em formato Markdown.

> **Nota de Confidencialidade:** Todos os dados, tabelas e valores presentes neste repositório são estritamente fictícios (Mock Data) ou anonimizados, criados exclusivamente para fins de demonstração arquitetural.
